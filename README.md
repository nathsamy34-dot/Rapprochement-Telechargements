# Rapprochement Comptable — Téléchargements

Page officielle de téléchargement de **Rapprochement Comptable**, l'application
Windows de rapprochement entre vos deux logiciels comptables.

## Installer ou mettre à jour

➡️ **[Télécharger la dernière version](https://github.com/nathsamy34-dot/Rapprochement-Telechargements/releases/latest)**
— prenez le fichier `Rapprochement-Comptable-X.Y.Z-Setup.exe`.

1. Double-cliquez sur le fichier téléchargé.
2. Si Windows affiche « Windows a protégé votre ordinateur » (SmartScreen),
   cliquez sur **« Informations complémentaires »** puis
   **« Exécuter quand même »** — l'avertissement est normal pour un logiciel
   diffusé hors du Microsoft Store.
3. Suivez l'assistant. Aucun droit administrateur n'est nécessaire, et
   **rien d'autre n'est à installer** : l'application est autonome.

**Mise à jour :** même geste. Le nouveau Setup s'installe par-dessus l'ancienne
version et conserve toutes vos données, préférences et licence. L'application
vous signale d'ailleurs elle-même, au lancement, quand une nouvelle version est
disponible ici.

## Prérequis

- Windows 10 ou 11, 64 bits.
- C'est tout.

## Au premier lancement

Une période d'essai de 30 jours démarre, toutes fonctions ouvertes. Pour
activer une licence : collez la clé `RC1-…` reçue de l'éditeur dans la barre
latérale de l'application. La vérification est 100 % locale — l'application ne
transmet aucune donnée.

## Historique des versions

Chaque version publiée est listée dans l'onglet
[Releases](https://github.com/nathsamy34-dot/Rapprochement-Telechargements/releases).
Le détail des nouveautés est livré avec l'application (CHANGELOG).
